# Dub Sub Hub logo concepts — v5: Orange relay

Both concepts combine the three-part wordmark and orange gradient from [v2/01-orange-field.svg](../v2/01-orange-field.svg) with the overlapping speech bubbles from [v4/02-dialogue-relay.svg](../v4/02-dialogue-relay.svg).
