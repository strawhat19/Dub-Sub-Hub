# Dub Sub Hub — V4 logo concepts

V4 explores compact marks for dubbing and subtitles alongside a dark player lockup. The set follows the orange playback and caption language in [V1](../v1/README.md) and [V3](../v3/03-caption-mark.svg). These are editable SVG concepts, not app assets.

| Concept | Direction | Suggested use |
| --- | --- | --- |
| [01-play-caption-bubble.svg](01-play-caption-bubble.svg) | Playback and subtitle lines in one speech bubble. | Small avatar or player control. |
| [02-dialogue-relay.svg](02-dialogue-relay.svg) | An audio waveform passes into a caption bubble. | Translation feature or app mark. |
| [03-night-player-lockup.svg](03-night-player-lockup.svg) | A player tile next to a three-part wordmark on charcoal. | Splash screen, header, or video slate. |

The palette uses orange `#F47B3F`, highlight `#FF9A57`, charcoal `#211711`, and cream `#FFF0E2`. The first two marks have transparent backgrounds; the lockup has an opaque charcoal field. The lockup keeps its text editable and requests Avenir Next or Inter, then Arial, so exact word spacing can vary with the available font.
